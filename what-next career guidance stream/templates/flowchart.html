Product flow

From first question to next step

See how the browser, Flask backend, and MySQL database work together to turn your answers into a career roadmap.

Frontend Backend Database
  1. 01
    Frontend

    Open the platform

    The student starts at the home page and chooses to create an account or log in.

    GET /
  2. 02
    Backend

    Authenticate the student

    Flask validates the submitted details, hashes passwords, and creates a session.

    POST /register · POST /login
  3. 03
    Database

    Store the account

    MySQL stores the user profile. The schema is initialized from database.sql on the first request.

    users
  4. 04
    Frontend

    Answer the interest test

    The signed-in student selects a 0-3 answer for every published question.

    GET/POST /interest-test
  5. 05
    Backend

    Score the answers

    Flask validates every answer, calculates category scores, and chooses the top category.

    score_and_record()
  6. 06
    Database

    Save the result

    The score snapshot is saved so the student and admin can view the latest attempt later.

    quiz_results
  7. 07
    Backend

    Build recommendations

    The selected category loads its courses, colleges, jobs, and roadmap from the recommendation data.

    GET /result
  8. 08
    Frontend

    Explore the next move

    The result page presents a clear direction, and the student can continue to courses, colleges, jobs, or the roadmap.

    /courses · /colleges · /jobs · /roadmap
Operations

Admin and deployment path

Admins sign in at /admin/login to manage questions through the protected API. Render runs the GitHub repository with Gunicorn, while the hosted MySQL provider keeps user, question, and result data persistent.
